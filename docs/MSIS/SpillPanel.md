# SpillPanel

Component in [[Screen Layout]] right panel.

## What

Shows [[Spill Pipeline]] results after [[Upload]] + [[Detect]].

## Displays

- 5-stage pipeline status
- [[Investigate]] vessel rankings
- Score bars (proximity, temporal, trajectory, anomaly)
- Drift data from [[Trace]]
- [[Export]] buttons (CSV + GeoJSON)
