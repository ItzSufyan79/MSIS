# Export

Output formats from [[Spill Pipeline]].

## CSV Report

- eventId
- classification
- confidence
- area (km2)
- historic match

## GeoJSON

- Spill polygon (msis-spill-fill)
- Drift line (msis-drift)
- Forecast line (msis-forecast)
- Origin circle (msis-origin)
- Vessel points (msis-vessel)
