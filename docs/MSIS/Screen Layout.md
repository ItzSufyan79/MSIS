# Screen Layout

Single-page console layout.

```
+------------------------------------------+
|              TOP BAR                      |
+--------+-------------------+-------------+
| LEFT   |    3D GLOBE       |   RIGHT     |
| DOCK   |                   |   PANEL     |
+--------+-------------------+-------------+
|              BOTTOM BAR                   |
+------------------------------------------+
```

## Top Bar

- MSIS brand + Navy Eye SVG
- RESTRICTED OFFICIAL classification tag
- Live ZULU clock
- Status, layer count, entity count
- [[Upload]] tool toggle

## Left Dock (collapsible)

- [[3D Globe]] layer toggles
- 3D/2D projection toggle
- Dark/satellite base map toggle
- Collapse via ChevronLeft to icon rail

## Center

- [[3D Globe]] — all layers render here

## Right Panel (collapsible)

- [[SpillPanel]] — [[Spill Pipeline]] results
- [[Satellite Tracking]] — live satellite data
- [[Export]] buttons (CSV + GeoJSON)

## Bottom Bar

- [[Marine Intel]] (left) — ocean regions, historic spills
- Cursor Telemetry (right) — live LAT/LNG, SST, wind, sea state
- Keyboard shortcuts legend

## Keyboard Shortcuts

| Key | Action |
|-----|--------|
| L | Toggle layers |
| 3D | Toggle projection |
| M | Toggle map mode |
| R | Reset view |
| F | Fullscreen |
| ESC | Dismiss |
