# 3D Globe

The central map where everything renders.

## Tech

- Mapbox GL JS
- 3D globe projection
- Dark / satellite base styles

## Layers

### [[Spill Pipeline]] Overlays

- msis-spill-fill — spill polygon
- msis-origin — origin circle
- msis-drift — drift line
- msis-forecast — forecast path
- msis-vessel — vessel dots

### [[Satellite Tracking]]

- msis-satmon — satellite position, footprint, track

### [[Marine Intel]]

- msis-aoi — Area of Interest box

## Controls

- Click entity for details
- Scroll to zoom
- Drag to rotate
- 3D/2D projection toggle
- Dark/satellite base map toggle
