# Upload

Entry point of [[Spill Pipeline]].

## What

Drop a SAR/EO satellite image or drone photo into the app.

## How

- Component: [[UploadAnalyze]]
- Accepts drag-drop or file picker
- Validates file type (GeoTIFF, JPEG, PNG)
- Reads preview
- Triggers [[Detect]] stage
